 │ These steps are for the web Hub, since a terminal has no developer tools. │
 │ To find the call behind something the Hub shows, do it in the web Hub     │
 │ with the Network tab open, then give your agent the method and address.   │
 │   1. Open your browser's developer tools: F12, or Ctrl+Shift+I on         │
 │      Windows and Linux, or Cmd+Option+I on macOS. Chrome and Firefox      │
 │      both have them.                                                      │
 │                                                                           │
 │   2. Open the Network tab and pick the Fetch/XHR filter (XHR in Firefox)  │
 │      .                                                                    │
 │                                                                           │
 │   3. Use the Hub as usual. Each new row is one call. Click it to see its  │
 │      method, address and headers, and the JSON it answered under          │
 │      Response.                                                            │
