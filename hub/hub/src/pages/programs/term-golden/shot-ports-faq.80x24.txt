 ▾ Which open ports get a web address?
   Each listed port has a kind:

   - Web: a TCP port. It gets a web address, which carries HTTP
   (WebSockets included) and nothing else. The Hub does not check
   that the port speaks HTTP.
   - Other: a UDP port, or a port number known for a service that             ▄
   is not the web, such as 22 (SSH) or 5432 (PostgreSQL). It                  █
   shows "No web address".                                                    █
                                                                              █
   A program that listens only on 127.0.0.1 or ::1 is not listed              █
   here. Make it listen on 0.0.0.0 to have its port listed.
